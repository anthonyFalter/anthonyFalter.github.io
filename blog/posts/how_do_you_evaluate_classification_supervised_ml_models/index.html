How do you evaluate Supervised Machine Learning models using classification metrics?

August 18, 2026, 7:42 AM · Ross Elopre



As I was working on a small machine learning project about classifying each pixel's color in an image of a flower bouquet using K-Means algorithm to practice my skills, I have found that evaluation metrics differ from model to model. Metrics like Accuracy, Recall, and F1 only applied to my recent sandbox project in which I used naive bayes (GaussianNB) to predict NBA players that is likely to continue within 5 years using continuous features.

The evaluation metrics I used in the nba classification model however, didn't really apply to the pixel color clustering model. This is because of both model's innate nature, in which pixel clustering uses K-Means algorithm, which is an unsupervised learning model, while the NBA classification model is a supervised model.



Supervised? Unsupervised?

Supervised Learning is basically a type of machine learning that uses predictor/s and outcome variables in which, both variables must be labeled (already classified), and that the model should have a training (basically the student's answers to the test), and testing (basically the test's answer keys) data.

In Unsupervised Learning however, it doesn't have these testing and training datasets because it doesn't need one to begin with! one example is the pixel clustering project I made in which it clusters pixel colors using K-Means algorithm (More in-depth explanation about types of algorithms, and metrics used for each algorithm in later blogs) from the word cluster, it basically groups up every pixel based on their context using intelligent mathematical algorithms. So the reason unsupervised learning doesn't need testing and training datasets is because instead of predicting outcomes like how supervised learning works, unsupervised learning finds the hidden patterns, similarities within the dataset.



Key Classification Metrics used for Supervised Learning

In this part, I will be talking about the key classification metrics used for supervised learnings. I will be doing a comprehensive walkthrough towards their differences, when and where they are applied, and actual usage examples, so sit back and enjoy the show!

Types of classification metrics

  • Accuracy
  • Precision
  • Recall
  • F1
  • F-Beta

Not all metrics will be listed here like: ROC-AUC, Cross-Entropy Loss because I am planning to do an ever deeper dive on those topics in future blogs!



Confusion Matrix

Before diving into those metrics, we must first learn the foundation behind these terminologies. Confusion Matrix is basically a table used to evaluate the performance of a classification model. It compares predicted label against the actual labels and is split into 4 primary categories:

  • True Positive

    - The test result or prediction that is actually true and correct (matches the specified conditions).

  • True Negative

    - The test result or prediction that is actually false and is correctly classified as false (matches the specified conditions).

  • False Positive

    - The test result or prediction that is actually false but is categorized as true. (Does not match the specified condition, ex: patient doesn't have a deadly illness but is concluded to have one).

  • False Negative

    - The test result or prediction that is actually true but is categorized as false. (Does not match the specified condition, ex: patient does have a deadly illness but is concluded as none).



Classification Metrics

1. Accuracy

This metric basically answers: "Out of all the predictions made, how many were correctly classified?". This metric is generally used only on balanced dataset (datasets with equal class importance)

Formula

\[ \frac{\text{TP} + \text{TN}}{\text{TP} + \text{TN} + \text{FP} + \text{FN}} \]

In the real world, a great example for this metric is: if you are a student that has finished a quiz and, your teacher is now checking your work, that teacher will compare your answers to an answer list:

  • Student's Answer: A | Correct: A
  • Student's Answer: B | Correct: A
  • Student's Answer: C | Correct: C
  • Student's Answer: D | Correct: D
